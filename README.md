# ButDesign

ButDesign ist eine responsive, statische Website für Design-Templates, Branding-Kits und Ressourcen für Barbershops und Grooming-Brands.

## Live lokal öffnen

`index.html` im Browser öffnen. Es ist kein Build-Schritt erforderlich.

## Deployment auf GitHub Pages

1. Repository öffnen: **Settings → Pages**
2. Unter **Build and deployment** `Deploy from a branch` wählen
3. Branch `main` und Ordner `/ (root)` auswählen
4. Speichern

## Struktur

- `index.html` – Landingpage und Inhalte
- `styles.css` – responsives Design
- `script.js` – mobile Navigation und Template-Filter

## Anpassung

Texte, Preise und E-Mail-Adresse können direkt in `index.html` angepasst werden. Farbvariablen befinden sich am Anfang von `styles.css`.
